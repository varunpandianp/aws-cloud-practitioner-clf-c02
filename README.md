# AWS Certified Cloud Practitioner (CLF-C02)

## About This Repository

This repository documents my learning journey towards the **AWS Certified Cloud Practitioner (CLF-C02)** certification.

I am following the [KodeKloud – AWS Cloud Practitioner CLF-C02](https://kodekloud.com/courses/aws-cloud-practitioner-clf-c02) course to understand AWS cloud fundamentals, core services, security, pricing, billing and support.

The goal is to build strong foundational AWS knowledge through structured notes, practical exercises, service comparisons and exam preparation.

- Understand cloud computing and its benefits.

- Understand the AWS Shared Responsibility Model.
- Learn IAM, security and compliance fundamentals.
- Explore AWS compute, storage, networking and database services.
- Understand monitoring, management and application integration services.
- Learn AWS pricing, billing and cost optimization.
- Practise AWS hands-on exercises.
- Prepare for the CLF-C02 certification exam.
